# Release and packaging changes

Version 2.0.0 presents the complete theorem and its machine-checked proof from
combinatorial definitions. Manuscript version 4 adds the formal verification
section and exact principal theorem statements. Repository prose and citation
metadata were updated to match this proved scope. Lean proof code is unchanged: only explanatory comments were revised in the
modules identified by `lean/source-preservation.json`. All configuration files,
verification programs, computational data and computational evidence remain
byte-identical to version 1.1.0. The formal
evidence under `evidence/lean/` was regenerated by building all 42 modules
from a new ordinary source clone without any existing project build objects.
The nine pinned dependency revisions were checked; their prebuilt objects were
reused. Every requested type and axiom report and both explicit semantic
expansions passed. `retained-files.json` records the preserved files;
`MANIFEST.json` records all distributed files except itself. The following
paragraphs describe the earlier packaging history.

Version 1.1.0 adds the combinatorial Lean development, final theorem wrappers,
and the source/type/axiom audit driver. The original algebraic proof modules
are unchanged. Formal evidence under `evidence/lean/` was regenerated by an
explicit build of all 42 Lean modules from a fresh source clone, followed by
the theorem, semantic-expansion and executable-check audits. Matching pinned
prebuilt dependency objects were reused. The computational sources, data,
manuscript and computational evidence from version 1.0.0 were retained without
rerunning them; `retained-files.json` records their exact hashes. The remaining
notes describe the earlier version 1.0.0 packaging changes.

All mathematical algorithms, input bounds and exact-arithmetic checks were
retained. Changes from the preserved source version:

- `src/verification/run.sh`: default output directory is `./results/literal`;
  invoke `python3` explicitly instead of `python`.
- `src/verification/check_series.py`: default input/output directory is
  `./results/literal`.
- `src/verification/algebra_flint.py`: remove a contributor identifier from its
  module docstring; the referenced separate implementation remains identified
  by filename.
- `src/general/blocks_all.py`: replace a fixed absolute output path with an
  optional second command-line argument (complete output filename), defaulting
  to `blocks_symmetry_nN.json` in the current directory.
- Move the three independent oracle scripts under `src/review/` and the two
  block programs under `src/general/`; sibling imports are preserved.
- Write `src/README.md` afresh with standalone commands and scope.

All production and independent-check logs were regenerated with relative paths
and are complete standard output plus standard error. Historical `small.json`
and `factored-small.json` are retained unchanged as supplemental algebra data;
no claim that these two supplementary files were regenerated is made. The
current full algebra result supersedes their smaller scope.

Timing and source-hash metadata naturally change between runs. The evidence
comparison report identifies exactly the changing JSON fields and verifies
stable mathematical content separately. No data values were edited.
